Program Huffman w C

Opis
Aplikacja realizuje kompresję oraz dekompresję plików tekstowych z wykorzystaniem algorytmu kodowania Huffmana.
Algorytm konstruuje optymalne drzewo binarne na podstawie częstotliwości występowania znaków w pliku wejściowym. Znaki pojawiające się częściej otrzymują krótsze kody binarne, co pozwala zmniejszyć rozmiar danych.
Pliki wyjściowe zapisywane są w formacie binarnym

Wymagania
Kompilator języka C (gcc)
System operacyjny obsługujący pliki tekstowe i binarne
